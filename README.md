# AI Workshop - OpenEdge ABL Project

This repository contains an OpenEdge ABL workshop project demonstrating the Business Entity Architecture Pattern.

## Project Structure

- `src/business/` - Business entity classes and datasets
- `src/*.w` - UI window files
- `.windsurf/` - Windsurf IDE rules and workflows
- `doc/` - Documentation

## Getting Started

1. Install OpenEdge ABL 12.8
2. Open the project in Windsurf or VS Code with OpenEdge ABL extension
3. Connect to the Sports2000 database
4. Build the project
